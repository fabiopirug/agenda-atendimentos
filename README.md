Agenda de Atendimentos
 
Programa simples em C para registrar e consultar atendimentos de uma empresa.
 
Funcionalidades
 
- ✅ Cadastrar atendimento
- ✅ Listar todos os atendimentos
- ✅ Buscar atendimento por nome
 
Como usar
 
1. Compile no terminal:  gcc agenda.c -o agenda 
2. Execute:  ./agenda 
3. Digite a opção desejada e siga as instruções na tela
